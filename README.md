# 📊 Power BI Table & Matrix Visualizations

---

# 📌 Overview

This project demonstrates the usage of **Table** and **Matrix** visuals in Power BI for displaying detailed and summarized business data effectively.

These visuals help users:
- analyze structured data
- compare values easily
- create hierarchical reports
- improve dashboard readability

---

# 📋 Table Visual

### Definition:
A **Table visual** displays data in a simple row-and-column format similar to an Excel table.

### When to Use:
- Display detailed records
- Show transactional data
- Present row-level information
- Enable easy filtering and sorting

### Features:
- Supports sorting
- Allows filtering
- Displays detailed data
- Easy to export data

---

## Example Table Visual

| Fund Name | Category | Return 1Y |
|---|---|---|
| ABC Fund | Equity | 12.5% |
| XYZ Fund | Debt | 8.2% |
| PQR Fund | Hybrid | 10.1% |

---

# 📊 Matrix Visual

### Definition:
A **Matrix visual** is similar to a Pivot Table in Excel and is used for summarized and hierarchical analysis.

### When to Use:
- Compare grouped data
- Create hierarchical reports
- Analyze category-wise summaries
- Perform drill-down analysis

### Features:
- Row and column grouping
- Drill-down functionality
- Dynamic summarization
- Better category analysis

---

## Example Matrix Visual

| Category | Average Return | Total AUM |
|---|---|---|
| Equity | 14.2% | 50000 |
| Debt | 8.7% | 30000 |
| Hybrid | 11.5% | 20000 |
